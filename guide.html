수정하면 바로 바뀌는
우리 연구실 홈페이지.

파일을 내려받거나 GitHub에 다시 올릴 필요 없이, 편집 화면에서 글과 사진을 바꾸면 홈페이지에 자동 저장됩니다.

콘텐츠 편집 ↗연구 사진·논문 편집 ↗홈페이지 보기 ↗

이렇게 수정하세요

  1. 콘텐츠 편집을 열고 이 홈페이지를 만든 ChatGPT 계정 또는 등록된 공동 편집자 계정으로 로그인합니다.
  2. 왼쪽 메뉴에서 첫 화면·연구분야·지도교수·Members·Publications·Gallery·연락처를 선택합니다.
  3. 글이나 사진을 바꾸면 자동 저장됩니다. 입력을 멈춘 뒤 ‘저장 완료 · 홈페이지에 반영됨’ 표시를 확인합니다.
  4. 오른쪽 미리보기나 홈페이지에서 결과를 봅니다. 다른 화면에서 열어 둔 홈페이지도 약 5초 안에 새 내용을 불러옵니다.

제목을 지우거나 새 영역을 추가하려면

모든 제목과 안내 문구는 선택 사항입니다. 입력 칸을 비우면 홈페이지에서도 사라집니다. 각 페이지의 ‘페이지 제목 · 버튼 · 안내 문구’에서 큰 제목, 작은 영문 제목과 버튼을 수정하세요. ‘공통 문구’에서는 메뉴와 하단 문의 영역을 바꿀 수 있습니다. ‘영역 표시 · 숨기기’의 체크를 끄면 영역 전체가 숨겨지고, 다시 켜면 내용이 복원됩니다.

각 페이지 아래의 ‘자유 글·사진 영역 추가’로 원하는 제목·본문·사진·버튼을 더할 수 있습니다. 위아래 화살표로 목록 순서를 바꾸고, 삭제 버튼으로 없앨 수 있습니다. 오른쪽 미리보기의 글이나 사진을 누르면 해당 수정 칸으로 바로 이동합니다.

사진과 약력도 직접 바꿀 수 있어요

사진은 파일 선택으로 업로드합니다. PNG·JPG·WebP를 지원하며 한 장당 최대 8 MB입니다. 교수님 경력·학력과 연구분야는 추가·삭제 버튼으로 항목을 바꿀 수 있습니다. 항목 삭제도 자동으로 반영됩니다.

연구별 사진 여러 장과 관련 논문

연구 이미지 한 곳에 여러 사진을 넣고 개별 폭(25–100%)을 조정하거나 관련 논문 제목과 링크를 넣으려면 연구 사진·논문 편집 도구를 이용하세요. 이 보조 편집기는 자동 저장이 아니므로, 수정 후 JSON을 내려받고 기존 콘텐츠 편집기의 백업 불러오기에서 해당 파일을 가져온 다음 저장 완료 상태를 확인해야 실제 홈페이지에 반영됩니다. 백업을 가져오면 사이트 전체 콘텐츠가 갱신되므로 동시에 편집 중인 사람이 있는지 확인하세요.

Members · Publications · Gallery

Members: 현재 구성원과 졸업자를 추가하세요. 이름·학위·직위·소개·기간·소속을 자유롭게 입력하고 사진을 업로드할 수 있습니다. 사진이 없으면 흰 배경의 기본 인물 이미지가 표시됩니다. ‘졸업자 목록으로 이동’으로 구성원을 옮기고 졸업 연도를 입력할 수 있습니다.

Publications: 교수님의 Google Scholar·ResearchGate 등 실제 프로필 주소를 등록하면 지도교수 페이지와 논문 페이지에 함께 표시됩니다. 논문은 항목별로 입력하거나, 한 줄에 한 편씩 참고문헌을 붙여넣을 수 있습니다. 붙여넣기 후 연도를 확인하세요. 등록된 논문은 연도별로 묶이며 검색과 연도 필터를 사용할 수 있습니다. 외부 사이트의 논문을 자동으로 수집하는 기능은 없습니다.

Gallery: 사진을 한 장씩 추가하거나 여러 장을 한 번에 선택하세요. 각 사진의 날짜·소제목·설명을 수정할 수 있습니다. 홈페이지에서는 여러 사진이 격자로 보이며, 사진을 누르면 확대하고 좌우 버튼·방향키로 이동할 수 있습니다.

저장 상태를 확인해 주세요

  • 저장 완료: 다른 기기에서도 같은 내용이 보입니다.
  • 미저장: 화면의 안내에 따라 입력 내용을 확인하거나 인터넷 연결 후 ‘지금 저장’을 누릅니다. 다른 곳으로 이동하기 전에 저장 완료 표시를 확인하세요.
  • 다른 화면에서 수정한 경우: 현재 수정본을 ‘백업 저장’으로 보관한 뒤 ‘최신 저장본 불러오기’를 누릅니다. 다른 화면의 수정 내용을 자동으로 덮어쓰지 않습니다.
  • 백업 불러오기: 불러온 내용도 자동 저장되어 홈페이지에 반영됩니다.

누가 편집할 수 있나요?

홈페이지 방문과 편집 권한은 별개입니다. 홈페이지는 공개되어 있고, 내용 수정은 관리자와 등록된 공동 편집자만 할 수 있습니다. 관리자는 편집 화면의 ‘공동 편집자 관리’에서 함께 작업할 사람의 ChatGPT 계정 이메일을 등록할 수 있습니다. 이메일 초대장은 발송되지 않으므로 편집 주소를 직접 알려주세요. 같은 내용을 동시에 바꾸면 충돌을 알려 다른 사람의 수정을 덮어쓰지 않습니다.

GitHub는 홈페이지 디자인과 페이지 코드를 제공합니다. 글과 사진은 연결된 저장 서버에 보관하므로 수정할 때마다 GitHub 파일을 다시 올릴 필요가 없습니다. 두 서비스가 유지되어야 자동 반영 기능을 사용할 수 있습니다.

배치·메뉴·글꼴처럼 디자인 자체를 바꾸려면 제작 대화에서 원하는 형태를 알려 주세요.
