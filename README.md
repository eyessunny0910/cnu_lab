# 연구실 홈페이지

홈페이지: https://eyessunny0910.github.io/cnu_lab/

편집: https://cnu-crop-genomics-lab.youngjun-moo-0109.chatgpt.site/editor.html

## 평소 수정 방법

1. 편집 주소를 열고 이 홈페이지를 만든 ChatGPT 계정으로 로그인합니다.
2. 왼쪽 메뉴에서 글·사진·교수님 약력을 수정합니다.
3. 저장 완료 표시를 확인합니다. 홈페이지는 약 5초 간격으로 새 내용을 읽습니다.

매번 파일을 업로드하거나 GitHub에서 코드를 수정할 필요가 없습니다. 공동 편집자는 편집 화면의 공동 편집자 관리에서 ChatGPT 이메일을 등록합니다. 별도 이메일은 발송되지 않습니다. 동시에 같은 내용을 수정하면 충돌을 알려 다른 사람의 수정을 덮어쓰지 않습니다.

## 구성과 유지 관리

GitHub Pages는 디자인·페이지 코드를 제공합니다. 글과 사진은 연결된 ChatGPT Sites 저장 서비스(D1/R2)에 보관하며, GitHub 방문 화면은 공개 읽기 API를 이용합니다. 이 서비스와 홈페이지가 함께 유지되어야 실시간 수정이 반영됩니다. 저장 서버의 전체 소스도 별도로 관리됩니다.

글과 사진의 수정은 GitHub 커밋을 생성하지 않습니다. 백업 저장 버튼으로 JSON 백업을 받을 수 있습니다. data.js는 연결 장애 시 표시할 초기 사본입니다.

Pages 설정: main 브랜치 / 루트. 디자인 코드를 직접 변경하면 GitHub Pages 배포 시간이 필요하지만 일반 콘텐츠 수정에는 재배포가 필요하지 않습니다. 원래 자료의 사진은 assets 폴더에 있습니다.

## 구성원 표시 순서 · 연구자 링크

구성원 직위에 `박사후연구원`, `석사후연구원`, `석사과정` 또는 `석사생`, `학부연구생`을 입력하면 홈페이지에서 **연구원 → 석사과정 → 학부연구생** 순으로 자동 분류됩니다. 각 그룹은 별도 행과 제목으로 표시되며 비어 있는 그룹은 숨겨집니다. 기존 등록 순서나 사진을 변경할 필요는 없습니다.

교수님 Google Scholar 및 ResearchGate URL은 편집기의 교수님 프로필 링크 항목에 입력합니다. 공식 링크가 비어 있으면 홈페이지의 두 버튼은 교수님 이름으로 검색하는 페이지를 대신 엽니다. 버튼에는 `연구자 검색` 표시가 붙으므로 공식 개인 프로필과 혼동되지 않습니다. URL에는 `https://`를 포함하는 것이 가장 확실합니다.
